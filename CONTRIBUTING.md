# Contributing

This repository contains production code used by UptimeFixer.

If you find a reproducible bug, please open an issue with:

- the affected tool or page
- steps to reproduce the problem
- expected behavior
- actual behavior
- browser and device details when relevant

For code changes, keep pull requests focused and avoid changing unrelated tool definitions or URLs.

Please do not include API keys, passwords, private customer data or production credentials in issues or pull requests.
