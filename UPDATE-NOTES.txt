UPTIME FIXER — CREATIVE HOMEPAGE UPDATE
Theme 4.1.0 | Plugin 2.4.1

INSTALL WITHOUT DELETING YOUR EXISTING SITE
1. Take a database + wp-content backup, or test on your staging copy first.
2. Appearance > Themes > Add New > Upload Theme: upload the updated theme ZIP.
   Choose Replace current with uploaded. Keep the existing alltools folder name.
3. Plugins > Add New > Upload Plugin: upload the updated plugin ZIP.
   Choose Replace current with uploaded. Do not delete/uninstall the old plugin first.
4. Leave Yoast activated. Do not run a demo import or reset its settings.
5. Settings > Permalinks > Save Changes once, then clear WordPress/CDN/browser caches.
6. The new layout is the front-page.php homepage. Existing posts, tool URLs,
   media, site logo and database settings are retained. If needed select your
   existing Home page in Settings > Reading. Do not create a second homepage.

SITEMAP / SEO
With Yoast active: keep XML sitemaps enabled in Yoast and check /sitemap_index.xml.
Without Yoast: WordPress core provides /wp-sitemap.xml.
robots.txt advertises the matching sitemap. Do not submit both generators.
Submit the active sitemap to Google Search Console after installing.
If Yoast explicitly excludes a page or post type, that setting is preserved.
A theme update does not guarantee indexing or search rankings.
